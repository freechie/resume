# John R. Molina — Software Engineer Resume

LaTeX source for the software engineer resume at [freechie.github.io](https://freechie.github.io/).

## Build

```sh
pdflatex John_Molina_Software_Engineer_Resume.tex
```

Needs a TeX install with `lmodern`, `hyperref`, `fancyhdr`, and `babel`. BasicTeX is enough if those packages are present.
